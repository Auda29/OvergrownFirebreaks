# Changelog

## 0.1.0-alpha.1

- Add 32 explicit conversions from Overgrown blocks to Burnt remnants.
- Add burn-removal tags for 13 Overgrown vines and infection corpses.
- Add a separate optional protection addon for 336 Burnt remnants.
- Restrict compatibility to Minecraft 1.21.1, Burnt 1.10.5.2 and Overgrown 0.1.2.
- Package the rules as data-only NeoForge JARs without requiring Paxi.
